IMPORTANT: THE OFFICIAL NEURIPS STYLE FILE
The source requires neurips_2026.sty from the official NeurIPS 2026 template.
The original style file is not included here, and no official template settings
should be changed. Open the official Overleaf template here:
https://www.overleaf.com/latex/templates/formatting-instructions-for-neurips-2026/bjdwqfdkyftc

HOW TO USE
1. Open the official NeurIPS 2026 template in Overleaf (Open as Template).
2. Keep its original neurips_2026.sty file unchanged.
3. Replace the template's main .tex contents with main.tex from this ZIP.
4. References are already included directly in main.tex for easy compilation;
   references.bib is also provided as an editable BibTeX source if desired.
5. Replace 'Student Name' and placeholder email in main.tex.
6. Confirm whether you are working individually or in a group, and edit
   Team Contributions accordingly.
7. Compile with pdfLaTeX (the in-file bibliography needs no BibTeX).
8. Inspect the final PDF: proposal must be at least two content pages,
   excluding references; submit individually on Brightspace by Nov 1, 2026.
9. Register the project team or solo project in the course Team Registration Spreadsheet.

PROJECT BOUNDARIES
- Core: 1D heat and 1D viscous Burgers with fixed-zero endpoint conditions.
- Neural operator: separate 1D FNO models and MLP comparators.
- Data: synthetic mathematical solutions and verified numerical simulations.
- Navier-Stokes: mathematical context and future work only, not an implementation deliverable.
- The proposed numeric hyperparameters are starting points, not completed experiments.
